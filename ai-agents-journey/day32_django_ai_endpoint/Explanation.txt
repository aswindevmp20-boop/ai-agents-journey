Until now:

    You ran agents via python agent.py

    Everything lived in terminal

Today:

    We expose your AI agent via a Django REST API endpoint.

This is how real AI systems are used:

    Frontend calls backend

    Backend calls AI agent

    Returns structured JSON response

Goal Today

    You will build:

        POST /api/agent/
        {
            "query": "Explain vector databases"
        }


    Response:

        {
            "response": "Vector databases store embeddings..."
        }


    That’s a real backend architecture.

Architecture

    Client (React / Postman)
            ↓
    Django API Endpoint
            ↓
    AI Agent Logic
            ↓
    Groq API
            ↓
    Return JSON Response

Set-up

Step-by-Step Setup

    Create Django Project
    pip install django djangorestframework groq
    django-admin startproject ai_backend
    cd ai_backend
    python manage.py startapp agent_api

    2️⃣ Register App

    In ai_backend/settings.py:

    INSTALLED_APPS = [
        ...
        'rest_framework',
        'agent_api',
