Day 56 — Self-Reflection Agent (Answer Critique Loop)

   We introduce a second evaluation step:

      Worker produces answer
            ↓
      Critic agent evaluates it
            ↓
      If weak → refine answer
            ↓
      Return improved answer

   So the AI now checks its own work.

   Why This Matters

      LLMs often produce:

         vague answers

         incomplete explanations

         hallucinated facts

      Self-reflection improves:

         accuracy

         reasoning quality

         reliability

   Architecture

      User Query
         ↓
      Workflow Agent
         ↓
      Initial Answer
         ↓
      Critic Agent
         ↓
      Refined Answer
         ↓
      Final Output
