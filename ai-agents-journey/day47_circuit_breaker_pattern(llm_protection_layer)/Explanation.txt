Day 47 — Circuit Breaker Pattern (LLM Protection Layer)

   Today we protect your system from cascading failures.

   This is a real distributed systems pattern.

   What Is a Circuit Breaker?

      Think of it like an electrical fuse.

      If too many failures happen:

      Stop calling the LLM

      Fail fast

      Let system recover

      Instead of:

         Fail → Retry → Fail → Retry → Hammer API → Crash

      We switch to:

         Fail repeatedly → Open circuit → Reject immediately → Cooldown → Try again

      Circuit Breaker States

         CLOSED     → Normal operation
         OPEN       → Blocking calls
         HALF-OPEN  → Testing recovery
